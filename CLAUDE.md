## The unit of change

Decisions go in pure functions: snapshot in, tagged union out, carrying a `reason`. Table-driven tests, no mocks. `ui/src/transport/media-event-policy.ts` is the template — copy its shape. (The former template, `auto-flip-policy.ts`, was deleted with SimplePeer in Phase 3.)

- **Exhaustive `switch` over a union type**, so an unhandled case is a compile error rather than a silent drop. `_dispatchMediaEvent` dropping five of eight `ConnectionPhase` members is the bug this prevents.
- **One authority per concept, one exported name.** A second implementation must delete the first. Adding a parallel path is the cheap wrong move and is how this codebase acquired 21 liveness sources.
- **Every important mock needs a negative control** — a test that fails if the mock cannot reproduce the bug the mock exists to catch. The motivating specimen: at the 2026-07 assessment `MockRTCPeerConnection` could not throw, so the `InvalidStateError` guard in `rtc-peer.ts` had no coverage and an inversion would have survived. The throwing-mock suite in `rtc-peer.test.ts` ("duplicate-answer InvalidStateError guard") closed that and is the template. (This bullet itself went stale as a negation — corrected 2026-08-03; see the "True today" contract.)
- **Chase decision coverage, not line coverage.** At the 2026-07 assessment the library sat near-fully covered while the orchestrator had no tests at all — and every production bug had been in the orchestrator. The wiring and construction suites closed the zero; the principle stands: coverage of decisions, not lines, is what predicts field behavior.
- **An abstraction not used as a type annotation gets deleted, not kept — or made real.** `PeerTransport` looked like a constraint and imposed nothing for three phases; Phase 4 made it the annotation on the store's transport fields, which is what turned "don't reach into the pc" from a review rule into a compile error.

## Working agreements

1. **Replace or declare.** Every change either names the mechanism it replaces, or states explicitly that it adds a parallel one and why. "Runs in parallel with X; X remains the source of truth" is how this codebase acquired four parallel models — it requires a justification, not a passing mention.
2. **No new threshold without a named predicate.** Six liveness clocks arrived one constant at a time. A new timeout must say which predicate it serves and reuse that predicate's clock.
3. **Prose cites code or gets deleted.** An invariant comment names the `file:line` it constrains. Active documents are corrected in place or deleted — no status ritual; a superseded or historical document MUST carry a `Status: SUPERSEDED (see X)` / `Status: HISTORICAL` header, following `docs/WEBRTC_PEER_CLAIM2_DATACHANNEL_GATING.md`. (Decided 2026-08-03; this rule previously demanded a header on every document while Phase 0 item 6 recorded that mechanism as rejected — the retro found the contradiction, and the practice won.) A design doc marks each item landed or not-landed once it ships. Living prose cites files and tests, not commit hashes — the Phase 1 branch rewrite invalidated four hash citations.
4. **Decisions become pure functions before they become complicated.** `ui/src/transport/media-event-policy.ts` is the template: plain-object in, tagged union out, table-driven tests, no mocks.
5. **The gate runs, or it isn't a gate.** A disabled workflow, an unrun typecheck, and an unenforced `strict` flag are all recorded intentions, not constraints.
6. **One intent per branch.**
7. **A conclusion may not dismiss field evidence on the strength of passing tests.** This happened (`12cb027`, then `c143cda` six weeks later proved it wrong) — at the time the mocks could not throw, so the suite was structurally unable to reproduce the field failure it was being cited against. Passing tests bound what the suite can see, never what the field can do.
8. **A fix names the symptom's previous fixes.** Use "supersedes `<hash>`" in the commit message. The same pane-survival symptom was fixed three times in three layers over 71 days, and the third broke an invariant the first documented.
9. **Every phase PR gets an adversarial review by a session that did not write it**, reading only the diff and the code. The second cause of the §3.1(c) wedge was found exactly this way, before the field found it. The authoring session's self-review converges to agreement with itself; independence is the property that caught it.
